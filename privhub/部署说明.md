# 私域枢纽 PrivHub 部署说明（纯 Cordis 架构 · 2026-08-28 v3）

> 底座：**纯 Cordis**（npm 依赖 `@deepseek-ai/cordis` 4.0.1，约 240KB），无 DSH 底座源码。
> 生产环境（privhub/）完全自包含：整个文件夹搬走即运行，references/ 删除不影响。

## 目录结构（18.7MB）

```
privhub/
├── src/             装配入口（main.ts：cordis Context + 自研 webServer + 插件挂载）
│   └── web-server.ts  自研 HTTP 服务（exact 路由 + 静态前端 + /privhub-plugins 映射）
├── plugins/         后端插件 + 纯前端插件（L1 六枢纽 / L2 能力 Service / L3 功能插件）
├── frontend/        前端（Vue 单页骨架 + manifest/slot 加载器 + vue.global.prod.js）
├── node_modules/    依赖（cordis / schemastery / tsx，约 12MB）
├── data/            运行数据（users/sessions/trash/audit 等，首次启动自动生成）
├── data-files/      文件存储根（顶层文件夹即项目）
├── start.bat        启动器（开发 3180 / 生产 3181）
├── package.json     依赖声明（3 个 npm 包）
├── .gitignore       上传 git 自动排除依赖与数据
└── 部署说明.md
```

## 启动

```bat
start.bat          -> 开发环境 http://127.0.0.1:3180
start.bat 3181     -> 生产环境 http://127.0.0.1:3181
```

## 架构（纯 Cordis 三层）

- **L1 六枢纽**：core（ctx.privhub 持久化/权限/回收站）+ auth + files + trash + admin + shell（manifest 聚合）；
- **L2 能力 Service**：audit / acl / watermark / search / meta（ctx.xxx 注入消费）；
- **L3 功能插件**：F01–F12（前端 slot 挂载 + 事件总线），另含 settings/favorites/recent 等后端；
- **webServer**：自研 Service（node:http），core 的 svc.route() 复用；静态服务直接提供 frontend/，
  插件 client 经 /privhub-plugins/<名>/<文件> 映射加载——不再需要 DSH 的 dist 接管。

## 插件开发

- 插件目录：`plugins/<名>/`，后端 `src/index.ts`（export const name / inject / apply），前端 `client/`（manifest.json + index.js）；
- 新增后端插件：在 `src/main.ts` 的 mount 列表加一行（import + config）；
- 纯前端插件：建 client/ 目录即可（manifest 聚合自动发现，浏览器动态加载）；
- 改代码即时生效（tsx 直接加载 TS 源码），重启 start.bat 生效。

## 依赖与参考

- 运行时依赖仅 3 个 npm 包（cordis / schemastery / tsx），`npm install` 即还原；
- `references/`（workspace 根）：完整底座源码与 llm-wiki 等参考资料，**仅供查阅/借鉴**，不参与运行；
- 后期若需借鉴 references 中的功能：将最精简的实现复制进 plugins/（不链接、不依赖）。

## 静态加密（S7，默认开启）

- 所有数据（用户文件 + 系统 JSON + 审计）以 AES-256-GCM 加密落盘，宿主机直接打开 data-files/ 或 data/ 无法读取内容（文件头 `PHENC1` / 审计块 `PHAUD1`）。
- 密钥：`data/secret.key`（32 字节，首次启动生成）；也可用环境变量 `PRIVHUB_SECRET` 覆盖。
- **密钥文件必须随数据一起备份——丢失密钥 = 数据无法恢复！**
- 旧明文数据迁移：`node --import tsx/esm ../scripts/encrypt-migrate.mjs`（在 privhub/ 目录执行；可重复运行，自动跳过已加密文件与密钥文件）。
- 关闭加密：`privhub/src/main.ts` 中 `svcStorage` 配置 `enabled: false`（读取仍自动识别密文）。

## 默认账号

- `admin` / `admin123`（系统管理员）
- `user1` / `user123`（普通员工，仅 公共 / A项目）

## 生产部署

- 打包：`powershell -ExecutionPolicy Bypass -File scripts/build-deploy.ps1` → `deploy/privhub-deploy/`（约 12.6MB）；
- 整包传输到宿主机 → 解压（任意路径）→ 双击 `start.bat 3181`；
- 首次启动自动生成 admin/admin123、密钥与数据目录；登录后请立即修改默认密码。
- **升级携带旧数据时**：把原 data/ 与 data-files/ 连同 secret.key 一并复制到新目录（数据在旧密钥下加密，复制密钥即可解密）。
