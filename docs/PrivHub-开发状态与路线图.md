## 1. 项目是什么（速记）

**PrivHub（私域枢纽）**：面向单个公司的局域网文件枢纽中心。一个 Node 进程同时伺服 HTTP API
与消费它的单页应用（SPA）；数据加密落盘、可私有化部署。

两个塑造一切的事实：

1. **没有构建步骤。** TS 源码经 `tsx/esm` 直跑；前端插件是浏览器直接 `import()` 的 ES 模块。
   改一个源文件 → 重启进程，就是全部开发循环。
2. **仓库根不是应用根。** 可运行应用在 `privhub/`；所有 npm / node 命令都在 `privhub/` 里跑。

三类顶层目录（混淆它们是安全 bug 的主要来源）：**项目** `data-files/<项目名>/`（按账号授权，
管理员见全部）；**个人空间** `data-files/<真实姓名>/`（仅本人可见，**管理员也不可见**，
永不自动删除，不进任何索引 / 查重 / 向量化）。

## 5. 质量闸门与已知状态点

- 无 lint / typecheck / `npm test` 脚本；唯一质量闸门是手写回归套件
  `cd privhub && node tests/run-all.mjs --spawn`（**硬拒 3180/3181** —— 那两个端口上跑着真实数据）。
- 最近一次全绿：HTTP **296/0**、integrity **181/0**、mcp-protocol **7/0**，静态套件全 0 失败（2026-10-15 收口后全量复跑，含「项目看板↔任务看板联动」批）。
- **已知偶发**（均**非断言失败**，单跑都全绿）：
  - `refcheck` 的「孤儿附件」断言偶报 `read ECONNRESET`（传输层连接被重置）；属既有套件的陈旧 keep-alive socket，未改。
  - **本机负载高时**，`refcheck` 的首个 `POST`（清理并新建测试项目 + 目录 + 文件）会撞 30s 请求超时，
    随后该套件其余断言因「环境没建起来」连锁红；`rag-resilience` 的「（前置）向量索引已建成」也会因
    mock 嵌入没在等待窗口内建完索引而红（`dims=null, state=idle`）。
    实测：2026-10-15 连跑 `run-all --spawn` 两遍各命中一次（HTTP 290/1、287/4，断言总数随批次增长，当时为 291）；
    单独拉起隔离实例单跑 `refcheck` 18/0（建环境 597ms）、`rag-resilience` 92/0，全绿。
    ⇒ 计为**环境抖动**，不是回归。（若将来在本机空闲时仍复现，再当缺陷查。）
