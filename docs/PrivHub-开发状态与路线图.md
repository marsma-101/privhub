## 1. 项目是什么（速记）

**PrivHub（私域枢纽）**：面向单个公司的局域网文件枢纽中心。一个 Node 进程同时伺服 HTTP API
与消费它的单页应用（SPA）；数据加密落盘、可私有化部署。

两个塑造一切的事实：

1. **没有构建步骤。** TS 源码经 `tsx/esm` 直跑；前端插件是浏览器直接 `import()` 的 ES 模块。
   改一个源文件 → 重启进程，就是全部开发循环。
2. **仓库根不是应用根。** 可运行应用在 `privhub/`；所有 npm / node 命令都在 `privhub/` 里跑。

三类顶层目录（混淆它们是安全 bug 的主要来源）：**项目** `data-files/<项目名>/`（按账号授权，
管理员见全部）；**个人空间** `data-files/<真实姓名>/`（仅本人可见，**管理员也不可见**，
永不自动删除，不进任何索引 / 查重 / 向量化）。
