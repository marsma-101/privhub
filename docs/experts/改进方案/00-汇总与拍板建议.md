## 四、各视角独有的高价值发现（不重叠，值得单独立项）

### 4.1 `01-don-norman.md`
- **P0-3 最坏的一条**：`core/index.ts:802-806` 的 `isValidName` **不拦"以点开头"**，而 `:701` 的 `listFiles` 把点开头条目**静默过滤**→ 建得成、看不见；且**搜索是递归 `listFiles` 的**，所以点开头目录的**整棵子树是搜索盲区**。〔我方已逐行复核，行号一字不差。旁证：`README` 里 `data-files/.agents/` 那批"测试残留"界面上看不到，正是此机制〕
- **P0-1**：`ops.js:87` 在 `:90` 的 `await` **之前**就把 `renameState` 置空 → 失败时输入框已消失、输入全丢、错误只报"重命名失败"。
- **同一前端两套水平**：管理控制台有分组导航、键盘选择、打字确认的危险操作、"待接入"态；**文件侧连"回到目录"都没有，Esc 也不管用**。现成的 `confirmAction` 只被调用过 2 次，explorer 一次没用。

### 4.2 `02-steve-krug.md`
- **骨架零响应式**〔我方已复核：`frontend/index.html` `@media` **0 条**；全仓仅 `admin-console/styles.js` 3 条〕→ 交底 U9 设想的窄屏 hover 气泡**在触屏上本来就不成立**。
- **点开 md/txt 直接进编辑态，切标签/切目录时静默保存**〔已复核：`tabs.js:52,68,84`〕——没有"未保存"提示。
- **中间栏过滤掉目录，导致目录分支成死代码**〔已复核：`panel.js:26` vs `:164`〕。
- **一份可照做的 3 人可用性测试脚本**（唯一能解决"五视角都没看过界面"这一共同盲区的资产）。
- 主动纠正了交底 U8① 已过期（我方已据此在交底作废该条）。

### 4.3 `03-refactoring-ui.md`
- **对比度是硬伤**：`--muted` 全档未过 4.5:1（浅 3.25/3.49/3.69，深 4.82/4.30/3.72），`--accent` 未过（4.12/3.44），**`.btn-primary` 主要按钮的白字只有 4.12（浅）/ 3.31（深）**。改 2 个 CSS 块、16 行内、**零插件风险**。
- **`admin-console/styles.js` 注释说作用域限定 `.admin-root`，实际只有 26 行带了它**；窄屏断点那 7 条规则**全是裸选择器**——宽屏有作用域、窄屏没有。
- 令牌表 17 张：间距/字号/圆角/阴影/语义色（明暗两套）共约 50 个变量 + 抽样 36 例 px 映射（每例带 `文件:行号`）。
- 自我纠正两次：`--ui-zoom` 误判死变量已改；P2-2 哨兵建议**前提被证伪已撤回**。

### 4.4 `04-alan-cooper.md`
- **「知识图谱」vs「知识库」是异物近名**（两个不同 view、两个插件，名字读不出区别）——**比"同物异名"更危险**，同物异名只多一次点击，异物近名会**点错功能**。
- **「回收站」是三块路牌一个 view**（图标栏 + 控制台侧栏 + `routes.js:48` 路由）。
- persona 四个（含一个"从不看界面的 AI 集成方"），全部标 `[推断]` 且**明确不为自己的 persona 背书**。
- 三条 P0 **只改字符串与 label**；刻意**不改 `view` 名**（会连带骨架 if-else 链与 8 处 `routes.js` 的 `entryOf`，成本从小跳到中）。

### 4.5 `05-shape-up.md`
- **串行漏斗**替代 betting table：`candidate → frame go → shape go`，一次一个，可直接当看板三列。
- **下一批成形清单 4 条** + **明确不做 15 条**（核心 N1：**入口重新定义完之前不再新增插件**）。
- **数据类功能必须走另一条车道**（按 37signals 自家《七条发布原则》，会动数据的属 high criticality）：本轮上传的 tmp+rename 原子写与软删除**做对了**，但 **Web 上传覆盖零备份、静默覆盖不查同名**。
- 修订后口径数（我方逐项核到个位）：活跃插件 **50** / 含 client **32** / 含 src **43** / A 组无 client **18** / B 组有 client 无 src **7**。

## 六、五视角共同的盲区（**比任何建议都重要**）

**五份方案里有四份在"判不了"一节写下了同一句话：我从没看过这个界面跑起来的样子。**

- 无浏览器、无截图、无真人使用、系统无埋点无日志 → **所有排序都是"看起来合理"，不是算出来的**。
- Cooper 说得最直白：那条"反比律"在本案**根本无法执行**，他明确不为自己的 persona 背书。

**⇒ 婢子的建议：本轮的第一步不是改代码，而是先补一次观察。** 两个可立即执行的选项：
1. 用 `02-steve-krug.md` 附的**3 人测试脚本**跑一次（他连"找不到 3 个人怎么办"的三档方案都写了）；
2. Norman 要的那份材料——**主子自己操作 5 分钟的一段录像**。"比再读一万行代码都更能指出路在哪里断。"
