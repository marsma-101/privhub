## 2. 早期生涯（1950s–1980s）摘要

- **出生地 / 成长**：1952-06-03 生于 San Francisco，在 Marin County 长大。来源：[CHM](https://computerhistory.org/profile/alan-cooper/) [一手]。
- **教育**：高中辍学 → College of Marin，主修建筑，取得 associate degree。建筑学训练是他日后「把软件当建筑来设计」的框架来源。来源：[CHM](https://computerhistory.org/profile/alan-cooper/) [一手]；建筑学与 Christopher Alexander 的影响见 [EvilGeniusLabs](https://evilgeniuslabs.ca/books/visual-basic-history/origins/vb-history-alan-cooper-and-tripod) [二手]。
- **第一份工作**：COBOL 程序员（约 1974–1975）。来源：[CHM](https://computerhistory.org/profile/alan-cooper/) [一手]。
- **1970s**：创办 Structured Systems Group（Oakland，1975 或 1976），General Ledger 被《Fire in the Valley》称为「probably the first serious business software for microcomputers」；参与 Gordon Eubanks 的 **CBASIC**；成为 **Digital Research** 研发部门四位创始人之一，约两年后离开。来源：[维基](https://en.wikipedia.org/wiki/Alan_Cooper_(software_designer)) [二手]（转引 Freiberger & Swaine）。
- **1980s**：1980 年售出 SSG 股份；独立编写 **SuperProject**（1983/1984 售予 Computer Associates）与 **_Microphone II_**。来源：[维基](https://en.wikipedia.org/wiki/Alan_Cooper_(software_designer)) [二手]。

**关于「I was a hippie programmer」类自述**：本次检索**未找到**该确切表述的一手出处。他的自述形象是「rebellious teenager / 走了少有人走的路」（[CHM](https://computerhistory.org/profile/alan-cooper/)），以及 1960 年代末的高中辍学与嬉皮时代背景。**若要引用「嬉皮程序员」这一说法，需另寻一手出处。** [推断]

## 3. VB 时期（1985–1991）关键链路

```
1985–1987  Tripod（自研，"shell construction set"，约 25k 行 C，Windows 2.x）
    ↓  向 Adobe / Lotus 等发行商演示均被建议去找微软
1987 末    经 Glen 牵线 → Gabe Newell 试看 → "Bill's got to see this"
1988-03    向 Bill Gates 及十余人演示（表单设计器实跑）
1988       Microsoft 收购 → 内部代号 Ruby；Tripod 代码全部作废
1988–1990  Cooper Software 作为外部承包商重写 18 个月 → 1990 初交付
1989–1990  原计划做 Windows 3.0 shell，被 OS/2 阵营以「逐像素一致」门槛踢出 build
           请求 Gates 回售自办发行 → 被拒（且受 NDA 限制）
1991-05-20 Microsoft Visual Basic 1.0 于 Atlanta Windows World '91 发布
1992       《Visual Basic How-To》献词 → "Father of Visual Basic"
```

要点（均见 [EvilGeniusLabs](https://evilgeniuslabs.ca/books/visual-basic-history/origins/vb-history-alan-cooper-and-tripod)、[CHM](https://computerhistory.org/profile/alan-cooper/)、[微软 1991 新闻稿转载](https://adamcaudill.com/2006/05/27/happy-belated-birthday-vb/)）：

- **Tripod ≠ Ruby ≠ 出货代码**。Tripod 是概念源头，出货的 VB 1.0 字节来自 Ruby 重写版。引用时不可混淆。
- **VBX 接口**（dynamically installable controls）通常归于 **Mike Geary** 在 Ruby 期的设计，而 CHM 与维基把 VBX 的创新归于 Cooper 的项目/团队。**署名归属存在微妙差异**，下游引用宜写「Cooper 的 Ruby 团队」。
- 微软收购金额**从未公开披露**。

## 4. 离开微软与转型（1988–1992）

- 卖断而非自办发行，是 Cooper 自己明确复盘过的取舍：Ruby 若自行上市「会让数百万人更快乐」，Visual Basic「让上亿人更快乐」（[EvilGeniusLabs](https://evilgeniuslabs.ca/books/visual-basic-history/origins/vb-history-alan-cooper-and-tripod)）。
- 1989–1990 的回售请求被拒 + NDA 约束，意味着他在 VB 出货前后**无法在公开场合触碰该产品**。
- 转型动因（本人自述）：早期就开始质疑软件构建的通行做法，认为行业漏掉了「用户如何与它交互」这一问（[维基](https://en.wikipedia.org/wiki/Alan_Cooper_(software_designer)) [二手]）。
- 与妻子 **Sue / Susan Cooper** 共同创办 Cooper（1990 或 1992 [冲突]）。
