📄 参考首页还原（一）：llm-wiki — jackwener 版

来源：references/llm-wiki（Apache-2.0）· 定位：CLI 工具 + AI Agent 技能系统 · 它的"界面"不是网页，而是 Obsidian（人机界面）+ 终端命令 + Agent 技能，以下是它呈现给用户的全部入口
💡 关键点：这个项目 没有自建 GUI——官方原话 "Obsidian is the human interface — no self-built GUI"。知识库目录本身就是 Obsidian 库，用户日常用 Obsidian 浏览，AI 代理用技能操作。它的"首页"= Obsidian 打开的 wiki 目录 + 4 个可调用技能。

🖥 终端界面（CLI 命令） 用户能看到的全部命令

# 安装
npm install -g @jackwener/llm-wiki

# 初始化知识库（唯一必做命令）
llm-wiki init  ← 创建 vault 结构 + 安装 4 个技能
llm-wiki skill install  ← 升级后刷新技能
llm-wiki status  ← 查看库状态
llm-wiki sync  ← 增量同步（mtime+SHA256）
llm-wiki search  ← 搜索（BM25 + CJK bigram）
llm-wiki graph  ← 知识图谱统计
日常使用其实是跟 AI 对话：/ingest 文章.md、/query "关于 X 我们知道什么"、/lint、/research "深入调研 Y"

📂 知识库目录（Obsidian 里看到的） vault 结构

my-wiki/
├─ CLAUDE.md ← 给 Claude Code 的引导（自动加载）
├─ AGENTS.md ← 给 Codex 的引导
├─ wiki-purpose.md ← 库的定位与读者
├─ wiki-schema.md ← 页面类型/命名/frontmatter 规则
├─ wiki-log.md ← 只追加的操作日志
├─ wiki/ ← AI 维护的知识页（Obsidian 兼容）
├─ sources/ ← 原始资料（只读不可变）
│  └─ YYYY-MM-DD/ ← 按日期存放
└─ .claude/skills/ ← ingest / query / lint / research
   .agents/skills/ ← 同四技能（Codex 版）

🧩 四个操作技能（用户/Agent 的"功能按钮"） ingest / query / lint / research

📥ingest 收录

原始资料 → 生成结构化 wiki 页面（frontmatter + wikilink + 来源可追溯），增量缓存

🔎query 查询

基于证据回答：先搜 wiki 页，答案带引用，找不到才回原始资料

🩺lint 体检

wiki 健康检查：断链、缺 frontmatter、过期页、命名不规范

🌐research 研究

外部检索 → 把结果收录成新 wiki 页（把"临时知识"沉淀进库）

📋 给用户的首页信息清单 这个项目呈现在用户眼前的东西

呈现位置内容
Obsidian 库wiki 页面树 + 双链图谱
终端init / skill / status / sync / search / graph
AI 对话4 个技能随时可调
页面本体Markdown + frontmatter + [[wikilink]]
结论：它没有"首页网页"，用户眼前的界面 = Obsidian（浏览/编辑）+ 终端（管理）+ 对话（操作）。
