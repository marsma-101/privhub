💡 所有可交互位点都带 hover 气泡，逐个悬停查看即可。
🏠 整个 App 框架 ds-app-shell（地基） 这是登录后进入的「主界面」外壳。它本身是 DSH 里的一个布局承载器，下面每个区域都是独立插件插进来的。
P-Hub 🏷️ 系统 LOGO / 名称 ds-ui-layout（顶栏区） 显示系统名（暂用 P-Hub 占位）。点击可回到根目录。
🗂 我的空间 / A项目 / 设计稿 🍞 面包屑导航 ds-file-tree（导航联动） 显示当前所在目录的路径，点击任意一级可快速跳回上层目录。
👑 管理员 🛡️ 权限标识 ds-auth-login 显示当前用户的角色（管理员/高层/普通用户）。不同角色看到的界面和能做的操作不同。
张 👤 当前用户 ds-auth-login 登录账号的头像。点击可打开个人菜单（改密码、退出登录）。
⏻ 退出 🚪 退出登录 ds-auth-login 注销当前会话，回到登录页。
🌲 左侧树形栏（整体） ds-file-tree 目录树。左键点击展开文件夹、切换当前目录；长按/右键弹出「复制/移动/重命名/删除」右键菜单。
文件目录
📁我的空间 根节点 ds-file-tree 每个用户登录后看到的「根」。普通用户只看到自己有权限的项目文件夹。
📁A项目 项目文件夹 ds-permission-scope 按项目划分的隔离区。负责 A 项目的人只能看到并操作 A 项目，看不到 B 项目。
📁设计稿 子文件夹 ds-file-tree 普通子目录，点击展开查看里面文件。
📁B项目 项目文件夹（无权时隐藏） ds-permission-scope 非本项目成员不可见。管理员/高层可看到全部项目。
🗑回收站 🗑 回收站 ds-recycle-bin（阶段二） 删除的文件先进这里，可恢复或彻底删除。防止误删。
📁 中间文件面板（整体） ds-file-panel 显示当前目录下的文件/文件夹。支持网格/列表两种视图，可排序、搜索。

➕ 新建 ➕ 新建 ds-file-ops 新建子文件夹（或空白文件）。
⬆ 上传 ⬆ 上传文件 ds-file-upload 点击选择文件上传，也可以直接拖拽文件到上传区。
⬇ 下载 ⬇ 下载 ds-file-upload 下载选中的文件。需要「下载」权限。
✂ 移动 / 复制 ✂ 移动 / 复制 ds-file-ops 把选中文件移动到其它目录，或复制一份。
🗑 删除 🗑 删除 ds-file-ops 删除选中项（进入回收站）。需要「删除」权限。
📥 拖拽文件到这里即可上传 📥 拖拽上传区 ds-file-upload（复用 DSH 拖拽能力） 把桌面/本机文件直接拖进这里 = 上传到当前目录。复用 DSH 现成的拖拽读取能力，省开发量。
📌 右侧可伸缩功能条（整体） ds-inspector 可伸缩的侧边信息/操作面板。显示选中项的详情、权限、操作入口。阶段一先做空壳，后续填充。
