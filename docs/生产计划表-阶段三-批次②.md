## 4. 全局硬性约束（每个步骤都适用）

1. **零污染**：不修改任何已落地基座代码（L1 六枢纽 + S1–S5 已实现部分）；增强一律 `ctx.intercept` / 事件钩子，禁止 `ctx.privhub.xxx = ...` 直接挂方法。
2. **事件契约**：跨插件通信走事件（file:\* / favorites:\* / auth:\* / trash:\* / meta:changed / audit:logged / upload:progress）；新事件需在《插件实现规则》登记。
3. **可插拔**：每个新功能独立目录，删目录 = 卸载且零残留（effect 逆序清理）。
4. **双环境**：开发 3180 / 生产 3181 行为一致；每步冒烟至少跑对应 3180 用例，步骤 0/10 必须跑 3181。
5. **安全**：所有新接口过 `requireUser` + 项目权限 + 路径安全（resolveInProject）；adminOnly 入口前端隐藏 + 后端二次校验。
6. **低配宿主机友好**：不引入需要构建链路的重型前端库；索引/扫描任务异步防抖，禁止阻塞事件循环。
7. **测试资产**：新冒烟脚本放 tests/，命名 `smoke-*.mjs`，统一 playwright + msedge headless 风格，随步骤提交。
