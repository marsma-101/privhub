## 一、一句话结论

**这套回归套件本身的质量，比"全绿"这两个字所暗示的高得多；问题不在测试写得差，而在"绿"这个信号没有口径、没有落盘、也没有把最该守的那几个地方包进来——于是它能证明"没更坏"，但证明不了"还能用"，而且换一台机器结论就会变。**

三个最要害的事实，各自独立可查：

1. **"全绿"没有权威数字。** 一键回归跑完后，工具自己只打印一行合计：`结果：86 通过 / 0 失败 / 共 86`（`run-all.mjs:94`）。而这次实际跑出来是 **282 条用例**（86 条打真实服务 + 196 条在 6 个独立脚本里）。工具不打印总合计，结果不落盘，所以"200 项""282 项"只能靠人拿 7 个数字相加。【实证】
2. **数字与记号都对不上。** 把本次回归的原始输出数一遍，**✅ 记号有 288 个**，脚本自报合计 **282 条**。差的 6 个里：7 个 ✅ 根本不是断言（`first-run.mjs:133` 每轮打一个 ✅，`audit-reliability.mjs:141,147` 打了 2 个 ✅），另有 1 条"计为通过却只打印 ℹ️"（`integrity.mjs:67-73`）。**数 ✅ 会多，数自报合计会少。** 【实证】
3. **最可能"改 A 坏 B"的那条路，自动化完全没守。** 4 个插件靠 `explorer-v3` 的内部类名工作（`.v3-content` / `.v3-md` / `.v3-text` / `.v3-loading`），而承载这些类名的 `panel.js` / `detail.js` **在现有 282 条用例里从来没有被真实渲染过一次**——只有正则文本检查。改一下渲染层，这 4 个插件会静默失效，回归仍然 282 全绿。【实体】

### P0-1　给"全绿"一个可信的口径：工具打印总合计 + 单独统计"跳过" + 结果落盘

- **【问题】**　"全绿"目前是一个**没有口径、没有出处、没有留痕**的说法。工具只打印单脚本合计（`共 86`），从不打印全场合计；跑完不写任何文件；而 288 个 ✅ 记号与 282 条自报用例对不上，6 条 `ok(true)` 与 1 条"ℹ️ 计入通过"混在里面。结果就是 `CHANGELOG.md:180` 那句"全量回归 **200 项通过**"——**无法复核、无法复算、次日即过期**（今日同口径是 282）。
- **【证据】**
  - `run-all.mjs:94`　唯一的总计行，只统计 7 个 HTTP 套件
  - `run-all.mjs:98-101`　静态脚本只取"退出码是否为 0"，不汇总条数
  - `lib.mjs:187-210`　`report()` 只有 pass/fail 两个状态，**没有 skip**
  - `first-run.mjs:133`、`audit-reliability.mjs:141,147`　打印 ✅ 但不是断言（共 7 个）
  - `integrity.mjs:67-73`　两个分支都 `pass++`，永远不红
  - `personal-rename.mjs:96-97`　一个 10 秒 `sleep` 被写成一条"通过用例"
  - `hardening.mjs:72`　`ok(n >= 0, ...)`，恒真
  - `CHANGELOG.md:180`　"200 项"的出处（v3.0.4，无细分、无原始输出）
- **【改法】**（三件小事，一次做完）
  1. 在 `tests/lib.mjs` 的 `report()` 里加第三种状态 **skip**，并把 `ok(true, ...)` 那 6 处改成显式的 `skip('原因')`——**skip 不计入 pass**；`integrity.mjs:67-73` 的 ℹ️ 分支同样改成 skip。
  2. 在 `run-all.mjs` 末尾汇总**所有**子脚本的输出，打印唯一一行权威合计：`总计 N 通过 / M 失败 / K 跳过`；K > 0 时在行尾附一句醒目提示（**不判失败**，避免为了绿而隐藏跳过）。
  3. 把这一行 + 本次运行的完整输出写进 `screenshots/<时间戳>/regression.txt`（该目录已被 `.gitignore:27` 忽略，不会污染仓库），并在 `CHANGELOG` 里只引用这一行。
- **【验收】**
  - 跑一次 `node tests/run-all.mjs --spawn`，末尾出现且只出现一行 `总计 282 通过 / 0 失败 / 0 跳过`（数字以实际为准）；
  - 把 `personal-rename.mjs:97` 那条改成 skip 后，**总数从 282 掉到 281、跳过从 0 变成 1**——**数字必须动**，这就是判别条件；
  - 故意把某条断言改成必失败 → 该行显示 `M=1` 且退出码非 0；
  - 操作提醒也写进说明：**不要用 `2>&1 | Out-String` 管道跑**，否则 PowerShell 会把一条中文 stderr 当成失败报 exit 1（实测真实退出码 0）。
- **【成本】** **小**（`lib.mjs` + `run-all.mjs` 各改十几行，测试只改 6 处 `ok(true`）
