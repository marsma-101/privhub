## 三、独立审核发现的回归（已修复）

审核的价值正在于此——它抓到了**我自己引入的问题**：

| 编号 | 审核发现 | 处置 |
|---|---|---|
| S1-a | `/api/agent/v1/write` 被全局 16MB 预检误伤，**破坏已发布的 200MB 契约** | 加入豁免名单，仅按各插件自身契约限制 |
| S1-b | 413 实际变成 `ECONNRESET`（`res.end()` 后立即 `req.destroy()` 触发 RST 吞掉响应） | 改为 `res.end(payload, () => req.destroy())`；实测 413 正确到达 |
| S1-c | chunked 请求绕过预检，且超限被 46 处 catch 误报成 400 | 两个内联 `readBody` 补上限 + `bodyStatus()` 区分 413/400 |
| N1 | `office-ui` / `office-ai` 保留无上限内联 `readBody`（已认证 DoS） | 补 20MB 上限 |
| N2 | RAG `type` 白名单漏了 `knownText` 分支 | 已由客户端转义兜底，本次未改（列为纵深防御待办） |
| N3 | 审计告警文案与实际不符（说"不会覆盖"，但 prune 会丢弃坏块） | 文案已修正为如实描述 |
| #3 | `allowSelfRegister` 开关**界面不可达**（服务端有、设置面板无） | 已在 `integrity` 记录；面板开关列为后续待办 |
| #1 | 迁移永久失败会导致审计停写 | 属设计上 fail-loud，已在文档说明 |

**审核同时确认了好消息**：D6 的 `withFileLock` 经 300 并发压测（进入临界区 0 次、最大同时进入 1）无提前放行；D9 哈希改造不会误命中或遗漏；S16 的 manifest 时序没有问题（Bearer 头自证身份，不依赖 `me()` 完成）。

## 四、测试有效性（重点说明）

审核明确指出：**"断言过弱"比"没有测试"更危险**。据此做了补强与**敏感性验证**：

| 测试 | 原状 | 处置 |
|---|---|---|
| S5 路径穿越 | **不可能失败**（`new URL` 把 `..` 归一化了） | 改用**原始 socket** 发未归一化请求 + 真实创建同前缀兄弟目录 |
| S9 彻底删除 | **零判别力**（用非删除者验证，修复前也通过） | 改为构造「删除者本人但已失去项目权限」的真实条件 |
| S2 发布页 CSP | 只查 `sandbox` 存在 | 增加断言 `allow-scripts` / `allow-same-origin` / `script-src unsafe-inline` **缺席** |
| S7 邀请码 | 只查长度 | 增加随机性检查（多次生成不重复 + 字符分布） |
| D10 加密 | 零覆盖 | 新增行为验证：写入后读盘断言文件头为 `PHENC1` |
| O1 部署包 | 零覆盖 | 新增 8 个关键文件逐字节比对 |
| D14 弃用 API | 零覆盖 | 新增静态检查（含 CRLF 注释剥离的坑） |
| 场景 3 启动保护 | `ok(!early)` 语义错误、无正向对照 | 改为 `first-run.mjs`：6 轮空目录冷启动 + 密钥稳定性 |

**敏感性验证**（证明测试真能抓到 bug）：
- 用**修复前的部署包**跑同一套测试 → **7 项失败**（含 D6 并发删除 24 次仅成功 4 次）；修复后全绿。
- 临时移除模板的 `v-pre` → 前端测试立即报错；还原后通过。

## 五、前端显示 bug

| 问题 | 现象 | 修复 |
|---|---|---|
| 模板占位符被当插值 | 提示文字显示「内容（ 会被替换为当天日期）」，`{{date}}` 位置空白，用户不知道要写 `{{date}}` | 该 `<label>` 加 `v-pre` |
| 水印被上传抽屉遮挡 | 上传期间右下角防截屏水印被完全盖住（安全功能失效） | 水印 `z-index` 999 → 2000 |
| 插件加载失败无提示 | 界面**永久停在「文件面板加载中…」**，错误只在 console | 骨架记录失败插件并显示可见原因 + 「重新加载界面」按钮 |
| 回收站角标恒为 0 | 写入的是无人读取的死变量 `trashBadge` | 改写入骨架的响应式 `badges.trash`，并在登录后主动加载 |

另修复：收藏重复 POST（双监听）、上传队列"假重试"（取消后永久停 ⏳）、`ph-table` 绕过 `api()` 丢失 401 提示。
