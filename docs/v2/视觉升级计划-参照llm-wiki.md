# PrivHub 视觉升级计划（参照 llm_wiki 桌面版）

> 日期：2026-08-30 · 状态：**计划待确认**
> 参照源：`references/llm_wiki`（Tauri 桌面应用，shadcn/ui + Tailwind 风格）
> 原则：**只动前端样式与骨架布局，不动服务端、不动插件逻辑、不动数据**

---

## 一、参照对象视觉特征（llm_wiki）

| 特征 | llm_wiki | PrivHub 现状 | 差距 |
|---|---|---|---|
| 色彩体系 | 中性色（oklch 无彩灰阶），深/浅各一套，几乎无彩色 | 蓝色 accent（#4a7bd6）+ 双色系 | 从「蓝调」转「中性专业风」 |
| 品牌色 | 无主色，靠 primary 深色按钮 + accent 悬浮层 | accent 蓝用于按钮/高亮/logo | 主色收敛 |
| 圆角 | 6px(lg 圆角 0.625rem) / 按钮 rounded-lg | 6px~12px 混合 | 统一为 8px 系 |
| 边框 | 1px `--border`（浅色 92% 灰 / 深色 12% 白） | `--line` #d8dee6 | 接近，微调 |
| 层次 | background / card / popover / muted / accent 五层 | bg / panel / panel2 三层 | 增加 hover/muted 层次 |
| 图标栏 | 48px 宽、38px 图标按钮、Tooltip 文字提示 | 52px 宽、38×34px、CSS title 提示 | 尺寸/提示方式对齐 |
| 字体 | Geist Variable + 系统回退 | 系统字体栈 | 保留系统字体（中文优先） |
| 间距 | 紧凑（py-2 / px-2.5 / gap-1.5） | 较宽松（padding 14px+） | 适度收紧 |
| 阴影 | 弹层/下拉 subtle 阴影 | 弹窗 box-shadow 0 16px 50px | 统一柔和阴影 |

## 二、视觉升级方案（最终呈现）

### A. 色彩体系（核心改动）
采用「中性灰 + 单色强调」专业风，保留深浅双主题：

**浅色**（对齐 llm_wiki :root）：
```
--bg:      #fafafa   （页面底色，比现在更白）
--panel:   #f5f5f5   （侧栏/面板 hover 层）
--panel2:  #ffffff   （卡片/顶栏）
--line:    #e5e5e5   （边框，更淡）
--text:    #18181b   （正文，近黑）
--muted:   #71717a   （次级文字）
--accent:  #3b82f6 或 中性 #18181b？（见待定项）
--danger:  #dc2626   （错误红）
--warn:    #d97706   （警告橙）
```

**深色**（对齐 llm_wiki .dark）：
```
--bg:      #18181b
--panel:   #1f1f23
--panel2:  #27272a
--line:    rgba(255,255,255,.12)
--text:    #fafafa
--muted:   #a1a1aa
--accent:  #60a5fa
--danger:  #f87171
--warn:    #fbbf24
```

> 强调色待定项：**方案1 中性深灰强调**（llm_wiki 原味，logo/选中态用深色块）｜**方案2 保留蓝强调**（更友好，其余对齐中性）——推荐方案2

### B. 布局细节对齐

| # | 区域 | 改动 |
|---|---|---|
| 1 | 图标栏 | 52px→48px；图标按钮 38×34→38×38 圆角 8px；hover/on 背景 `--panel2`+accent 文字；tooltip 用浅色底深色字 |
| 2 | 顶栏 | 背景 panel2、下边框 line；logo 圆点改 8px 圆角方块（品牌感）；项目下拉/欢迎 tab 圆角 8px |
| 3 | 目录树 | hover 背景 panel2；激活项 accent 淡底 + accent 文字；行高 30px 紧凑化 |
| 4 | 文件卡片/表格 | 卡片圆角 8px、hover 淡阴影；列表行 hover 背景 panel；表头 muted 小字 |
| 5 | 按钮 | 统一圆角 8px；主按钮 accent 底白字；ghost 按钮 line 边框 + hover 淡底；尺寸 h-8 |
| 6 | 输入框/下拉 | 统一 8px 圆角、focus 时 accent 边框 + 淡 ring 阴影（llm_wiki focus-visible ring） |
| 7 | 弹窗/模态 | 圆角 12px、阴影改 `0 8px 30px rgba(0,0,0,.12)` 柔和款 |
| 8 | 功能面板视图 | view-inner 背景 panel2、内容区 1100px 居中保留 |
| 9 | 滚动条 | 细滚动条（4px、圆角、hover 变深）——llm_wiki legend-scroll 风格 |
| 10 | 水印/角标 | 角标改 8px 圆角小圆点风格 |

### C. 字体与间距
- 字体栈保留 `-apple-system, "Segoe UI", "Microsoft YaHei"`（中文友好），可加 `Inter` 前缀做西文优化
- 全局间距从「宽松」向「紧凑」微调：main-head padding 14px 20px → 12px 16px；卡片 gap 12px → 10px

### D. 登录页
- auth-card 对齐：圆角 12px、阴影柔和、logo 圆点→圆角方块 + 品牌名、按钮圆角 8px

## 三、实施范围与风险

| 项 | 说明 |
|---|---|
| 改动文件 | 仅 `privhub/frontend/index.html`（CSS 变量 + 局部样式）——90% 改动集中于此 |
| 插件文件 | 无逻辑改动；仅当插件内联样式引用了旧色值时需同步（如 `rgba(90,130,200,.x)` 蓝色系 → 新 accent） |
| 兼容 | 深浅主题切换功能保留（D25）；`applyTheme` 不变 |
| 风险 | 低——纯样式；需跑全量 UI 回归确认无布局破坏 |
| 测试 | check-views / smoke-batch1 / closedloop / 各 check-* 全量回归 |
