# PrivHub 侧边栏/功能面板 最终优化方案（参考 llm_wiki 布局哲学）

## 一、llm_wiki 的布局哲学（调研结论）

llm_wiki 桌面端平衡「功能栏 / 内容显示」的核心规则只有 3 条：

| # | 规则 | 代码体现 | 效果 |
|---|---|---|---|
| 1 | **功能面板 = 视图，不是弹层** | `setActiveView(view)`，图标栏点击直接切换主内容区 | 无叠层、无残留、无互斥问题——同一时刻界面状态只有一个 `activeView` |
| 2 | **左栏只属于内容型视图** | `showLeftPanel = !isStandaloneView(activeView)`（settings/chat/skills 为 standalone） | 工具类视图独占全屏，左文件树自动隐藏；内容视图才显示左栏 |
| 3 | **右栏是伴随面板** | `hasRightPanel = !standalone && panelOpen` | 只在内容视图跟随显示，不抢注意力 |
| 附 | 面板可拖拽调宽（150~400px）、hover 高亮手柄、可折叠成 9px 竖条 | `app-layout.tsx` startDrag | 用户可控，但不改变「视图优先」的本质 |

**一句话：功能面板占主区（全屏视图），左栏只留给浏览上下文（文件树）。**

## 二、PrivHub 现状 vs 参考差距

| 维度 | PrivHub 现状（抽屉模式） | llm_wiki（视图模式） | 问题 |
|---|---|---|---|
| 功能面板形态 | 左栏抽屉（420~640px），挤在目录树旁 | 主区全屏视图 | 左栏双面板、挤压 main、小屏拥挤 |
| 状态模型 | 8 个独立开关 + 互斥 + toggle | 单一 `activeView` | 开关集合易产生「残留打开」 |
| 视图切换 | 抽屉不随视图关闭 | 视图天然互斥 | 切回收站/搜索时抽屉还挂着 → 乱 |
| 目录树 | 与抽屉并存 | 工具视图下自动隐藏 | 双左栏 |
| 功能面板宽度 | 280~760px 可拖拽 | 自适应主区 | 审计表格/图谱/知识库 在窄栏里局促 |

## 三、最终方案：功能面板视图化（对齐 llm_wiki）

### 3.1 核心改动
把 8 个功能抽屉改为**主区视图**（main 内容切换），目录树/右栏按视图类型自动显隐：

```
┌─────────────── topbar（常驻）───────────────────────────────┐
├──┬──────────────────────────────────────────────────────────┤
│图│  main（视图切换区）                                        │
│标│  ┌─ 文件浏览视图 ─┐  ┌─ 功能视图（设置/用户/权限/审计/…）─┐ │
│栏│  │ 目录树|文件面板 │  │ 该功能面板独占 main（全宽）        │ │
│  │  └───────────────┘  └───────────────────────────────────┘ │
└──┴──────────────────────────────────────────────────────────┘
```

| 视图 | 目录树（左栏） | 右侧预览 | 说明 |
|---|---|---|---|
| 文件浏览（默认） | ✅ 显示（0~420px 可拖拽） | ✅ 单击文件打开 | 唯一带左栏的视图 |
| 设置/用户管理/权限/审计/标签/模板/知识图谱/知识库 | ❌ 自动隐藏 | ❌ 自动隐藏 | 功能面板独占 main，全宽 |
| 回收站/搜索/收藏 | ❌（现状已隐藏） | ❌（现状已隐藏） | 不变 |

### 3.2 状态模型收敛
- 删除 8 个 `xxxOpen` 开关 + `closeAllDrawers` 互斥逻辑
- 新增单一 `nav.activeView: 'files' | 'settings' | 'admin' | 'acl' | 'audit' | 'tags' | 'template' | 'kg' | 'wiki'`（回收站/搜索/收藏沿用现有 flag）
- 图标栏点击 = `setActiveView(view)`；再点同一图标 = 切回 `files`（toggle 保留）
- **视图切换天然互斥**：永远只有一个视图，不存在「残留」

### 3.3 保留项
- ✅ 功能面板内容全部复用（模板、逻辑、API 不变，只改挂载位置）
- ✅ 图标栏高亮（activeView === view）
- ✅ 目录树可拖拽调宽/折叠（现状保留）
- ✅ Esc 回到文件视图（可选）
- ✅ 用户管理内的子弹窗（编辑/重置密码）保持居中弹窗

### 3.4 面板宽度策略（功能视图）
llm_wiki 是「全宽 + 内容自限宽」（settings 用 `max-w-3xl` 居中）。方案：
- 功能视图默认**占满 main**，内容区用 `max-width: 1100px; margin: 0 auto` 居中（宽屏不空旷）
- 不再需要抽屉拖拽手柄（宽度自适应），删除 `.drawer-col/.drawer-resize` 逻辑
- 审计表格/图谱/知识库获得完整宽度，体验显著提升
