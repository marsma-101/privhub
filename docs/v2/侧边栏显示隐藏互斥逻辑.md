## 二、各元素显示/隐藏条件（现状）

### 2.1 目录树（文件树侧边栏）
| 条件 | 显示 | 说明 |
|---|---|---|
| `nav.project !== null` | ✅ | 已进入某个项目 |
| `nav.trashView === false` | ✅ | 不在回收站视图 |
| 宽度 | 0~420px | `nav.sidebarWidth`，拖拽调整、双击折叠为 0、localStorage 持久化 |
| 隐藏场景 | — | 欢迎页（project=null）/ 回收站 / 搜索 / 收藏视图 时**不显示** |

### 2.2 功能抽屉（设置/用户管理/权限管理/审计/标签/模板/图谱/知识库，共 8 个）
| 状态 | 规则 |
|---|---|
| 打开 | 点图标栏对应图标（`openXxx` → flag=true） |
| 关闭 | 再点同一图标（toggle）、点面板内「关 闭」、按 Esc |
| 互斥 | **同时只开一个**：`closeAllDrawers()` 先关全部再开新的 |
| 宽度 | 每抽屉独立 280~760px（`drawerWidths[slot]`），拖右缘手柄调整、localStorage 持久化 |
| 与视图的关系 | **不随视图切换自动关闭**（切项目/回收站/搜索/收藏/欢迎时抽屉保持打开） |

### 2.3 主内容区（main）视图切换（nav 状态机）
| 视图 | 触发 | 标志 | 优先级（v-if/v-else-if 链） |
|---|---|---|---|
| 回收站 | 图标栏 🗑️ | `trashView=true` | 1（最高） |
| 搜索 | 图标栏 🔍 | `searchView=true` | 2 |
| 收藏 | 图标栏 ⭐ | `favView=true` | 3 |
| 欢迎页 | 点「🏠 欢迎」/ 删除项目 | `project===null` | 4 |
| 文件面板 | 进项目/切项目 | `project!==null` | 5（最低） |

互斥：`openDir/openTrash/openSearch/openFavorites` 会**互相清零**对方标志（三者互斥），且都清空 `rightOpen/selected/preview`。

### 2.4 右侧预览栏
| 条件 | 显示 |
|---|---|
| `nav.rightOpen === true` | 单击文件后打开（`selectEntry`），含图片/PDF/MD 预览 |
| 关闭 | 进入目录、切换视图、点欢迎页 |

## 三、互相干涉关系（现状 → 问题点）

| 场景 | 现状行为 | 问题 |
|---|---|---|
| 抽屉打开时切换项目 | 抽屉**保持打开**，项目照切 | ⚠️ 抽屉内容可能指向旧项目上下文（如审计筛选），视觉突兀 |
| 抽屉打开时进回收站/搜索/收藏 | 抽屉**保持打开**，视图照切 | ⚠️ 「左边挂着设置、中间是回收站」——状态不干净，用户感知乱 |
| 抽屉打开时点欢迎页 | 抽屉**保持打开** | ⚠️ 欢迎页 + 设置抽屉并存 |
| 目录树 + 抽屉同时打开 | **两者并存**（目录树 220 + 抽屉 420+） | ⚠️ 左栏双面板挤压 main，小屏更明显 |
| 抽屉打开时右侧预览 | 两者并存（左抽屉 + 右预览） | ℹ️ 可用，但左右都占空间 |
| 视图切换（回收站/搜索/收藏/欢迎/项目） | 关闭右侧预览、清选中 | ✅ 已干净 |
| 抽屉之间 | 严格互斥 + toggle | ✅ 已干净 |
| Esc | 关闭全部抽屉 | ✅ 已干净 |

## 四、优化方案（推荐）

**原则：视图切换 = 状态归零；左栏同一时刻最多一个面板。**

### 方案 A：视图切换时自动关闭抽屉（核心）
在 `nav.openDir / openTrash / openSearch / openFavorites / backToWelcome` 中调用 `closeAllDrawers()`（骨架持有）。
- 效果：任何视图切换（切项目/回收站/搜索/收藏/欢迎）都会收起抽屉，回到「干净」状态。
- 保留 toggle：用户想开抽屉就再点一次图标，成本极低。
- 影响面：骨架一处函数 + nav 五个入口点，无插件改动。

### 方案 B：抽屉打开时自动收起目录树（可选增强）
打开抽屉时若目录树展开（`sidebarWidth > 40`），自动记录并折叠为 0；关闭抽屉时恢复。
- 效果：左栏同一时刻只有一个面板，彻底消灭「双左栏」。
- 代价：需要记忆「打开抽屉前的目录树宽度」并在关闭时还原；目录树折叠动画依赖现有 `toggleSidebar`。

### 方案 C：抽屉与右栏互斥（可选，力度最轻）
打开抽屉时关闭右侧预览（`rightOpen=false`）。右栏是「文件浏览附属」，抽屉是「功能面板」，二者并存的场景价值低。

### 推荐组合
**A（必做）+ B（推荐）+ C（可选）**：
1. 视图切换自动关抽屉 → 状态永远干净（核心痛点）
2. 抽屉开时目录树自动让位 → 左栏单面板（视觉整洁）
3. 抽屉开时右栏自动关 → 双栏不打架

> 实施后仍保留：抽屉互斥、toggle、Esc、宽度记忆、目录树宽度记忆。
> 所有规则收敛为一句：**「一次只做一件事」——打开功能抽屉 = 独占左侧注意力；离开当前视图 = 一切归零。**
