## 一、架构层面对照

### 1.1 三层架构

| 层 | 文档定义 | 当前实现 | 结论 |
| --- | --- | --- | --- |
| L1 六枢纽 | 6 个宿主目录，已实现不动 | core/shell/auth/files/trash/admin 原样搬入 | ✅ 一致 |
| L2 能力 Service | S1–S6 | S1–S5 已实现并验证；S6 collab 批次② | ✅ 符合批次规划 |
| L3 功能插件 | F01–F27（批次① 12 个） | F01–F12 全部实现 | ✅ 一致 |

### 1.2 L1 域 Service 形态

文档第 2 节表格描述「6 枢纽各提供域 Service（privhub/auth/admin/files/trash/shell）」，同时明确「已落地、稳定、不拆、不动」。
当前实现：core 提供 `ctx.privhub` Service；auth/files/trash/admin 为函数插件（name/inject/apply + svc.route 注册路由），shell 提供 manifest 聚合。
**判定：按文档「已实现不动」原则保持现状，不做形态改造**（改形态 = 高回归风险，无生产收益）。文档第 2 节「务实处理」段落已认可此形态。

### 1.3 事件契约（重点差异，需修复）

文档定义事件（file:\* / favorites:changed / auth:\* / trash:\* / recent:updated / upload:progress / file:uploaded）：

| 事件 | 文档定义 | 当前实现 | 处理 |

| file:trash | F07 emit，F06/F07 监听 | ✅ doDelete emit（payload 用 name 当 id，无消费者依赖） | 一致 |

| upload:progress | F11 emit，F12 监听 | ✅ | 一致 |
| **file:uploaded** | F11 emit（触发防病毒钩子），F12 监听 | ❌ 未 emit | **补** |

### 1.4 Slot 契约

文档 7 slot：auth / project-tabs / user-area / app-iconbar / tree / panel / preview。
当前实现：7 个基础 slot + 10 个视图级扩展 slot（tabs / trash-view / search-view / fav-view / settings / watermark / upload / upload-queue / welcome / admin）。
**判定：扩展是「视图切换」层面的自然演进，机制一致（manifest → 动态 import → slot 渲染）。需把完整 slot 清单落文档。**

### 1.5 barItems 契约

文档：`{ icon, title, slot, adminOnly }`。当前扩展 `view` 字段（点击分发：files/trash/search/favorites/settings/admin）。
**判定：向后兼容扩展，落文档。**

### 1.6 接口清单

文档《设计与实施》22 个（旧版基线）。当前 28 个路由 = 原 22 个超集 + settings/favorites/recent/search/watermark 5 个新增。
**判定：超集符合预期。缺「下载」接口（见 2.x，需求 5.2 明确列出）。**

## 结论（2026-08-28 修复完成）

- **P0 全部完成并验证**：下载接口（/api/download，中文文件名 RFC 5987）+ 右键/批量下载入口；事件契约补齐（auth:login/auth:logout、file:uploaded、file:restored、favorites:changed、recent:updated 全部按文档 emit）；D25 默认视图登录时生效；回收站 30 天自动清理（trash 插件定时器，Cordis effect 可逆，ttlDays/intervalHours 可配）；测试数据清理（audit/acl/meta/favorites/recent/settings 删除、sessions/trash 清空）；顶层 package.json 修正（去除虚假依赖声明）。
- **P1 全部完成并验证**：A2 面板拖拽调宽 + 双击折叠（宽度 localStorage 持久化）；搜索输入即筛选（500ms 防抖）；批量移动（新接口 /api/move + 批量工具栏按钮，同卷 rename、路径安全校验）。
- **P2 明确暂缓（记录理由）**：Office 预览转换（依赖 LibreOffice/转换服务，低配宿主机评估后做）；批量 zip 下载（需 zip 库，当前逐文件下载可接受）；B12 失败自动重试（当前「重选同名文件」方案可接受）。
- **回归**：smoke-batch1.mjs（3180 开发 + 3181 生产）全部通过、零控制台错误；inspect 系列全过。
- **仍记录不改的架构项**：L1 域 Service 形态（函数插件 + ctx.privhub，符合文档「已实现不动」）；slot 扩展（10 个视图级 slot）与 barItems.view 字段（向后兼容扩展，清单见部署说明）。
